01 · Overview

Detailed when you need it. Clear at a glance.

The Advanced layout brings together current conditions and configurable weather details. Choose a modern Cards view or a compact List view.

  • Choose which weather metrics to display
  • Show two temperature metrics at the same time
  • Switch between Cards and List presentation
02 · Forecast

Forecasts that adapt to the way you read them.

Move between daily and hourly outlooks. Use a quick Strip, glanceable Cards, familiar Standard rows or rich Graphs.

  • Daily outlook up to 16 days and detailed hourly forecasts
  • Temperature, precipitation and optional data graphs
  • Expand a day to inspect its hourly forecast
  • Reorder graph details and keep graph scales aligned
03 · Radar

See changing weather on the map.

Follow precipitation with the interactive Radar tab. Choose RainViewer or LibreWXR as the radar source.

  • Interactive map with pan and zoom
  • RainViewer and LibreWXR support
  • Open the radar in your browser when embedded view is unavailable
04 · Compact modes

Your weather, right in the panel.

Keep essential conditions close without opening the full widget. Pick a single-line layout, a compact icon-and-temperature style or a multiline display.

  • Single-line panel layout
  • Simple and XFCE-style multiline modes
  • Advanced or tab-free Simple widget layouts

Weather alerts and notifications

Receive KDE notifications for forecasts, UV and space-weather updates, plus severe alerts from MeteoAlarm, NOAA NWS, LibreWXR, KDE’s FOSS Public Alert Server and supported provider sources. Configure notification types and sounds separately; an additional Purple severity tier highlights extreme alerts.

Location with precision

Use GeoClue2 for automatic detection or search manually with OpenStreetMap and Photon geocoding. The integrated OpenStreetMap picker lets you pin an exact location, while timezone, altitude and localized city names are detected automatically.

GeoClue2OpenStreetMapPhoton geocoding

Weather history

Look back across days, weeks and months using the free Open-Meteo Historical Weather API, independently of your forecast provider. Zoom and pan interactive charts for temperature, precipitation, wind and more; summary tiles include averages, extremes, rainfall, wind, sunshine, humidity, pressure and cloud cover.

Weather providers and adaptive failover

Use Adaptive mode to move to another supported source when a provider is unavailable, or select a provider yourself.

Regional models, wherever possible

When Open-Meteo is selected, the widget can prefer national high-resolution forecast models for more local detail — including DWD ICON, Météo-France AROME, UK Met Office, NOAA GFS/HRRR, MeteoSwiss ICON-CH, MET Norway, Environment Canada GEM, JMA, KNMI, DMI, ItaliaMeteo ARPAE and CMA.

Make it yours

Flexible layouts, not one fixed design

Adapt the amount of information, presentation and icon style to your panel, desktop and personal preferences.

Panel presentation

Choose a compact Simple style, a single-line layout or a multiline XFCE-style display with a scrolling information area.

Widget presentation

Use the Advanced layout with Details, Forecast, History and Radar tabs, or choose a Simple layout without tabs.

Forecast configuration

Choose daily Standard or Graphs, and hourly Cards, Strip or Graphs. Select the data series to show and reorder graph details independently.

Weather icon styles

Choose Symbolic, Font, Flat, 3D, Meteocons or KDE icon styles. Pick icons per item and optionally tune the weather-icon glow.

Get started

Install on KDE Plasma 6

The KDE Store is the recommended way to install the widget. Some optional features need additional Qt or KDE modules.

Recommended · KDE Store

  1. Right-click your desktop or Plasma panel.
  2. Select Add Widgets….
  3. Choose Get New Widgets → Download New Plasma Widgets.
  4. Search for Advanced Weather Widget and click Install.

Open KDE Store ↗

Manual installation · Development

To install from the source repository, run these commands in a terminal:

git clone https://github.com/pnedyalkov91/advanced-weather-widget.git
cd advanced-weather-widget
kpackagetool6 --type Plasma/Applet --install .
rm -rf ~/.cache/plasmashell/qmlcache
systemctl --user restart plasma-plasmashell

For development builds, follow the README instructions for the branch you are testing.

Qt Graphs is preferred and requires Qt 6.8 or newer. When it is unavailable, the widget falls back to KDE Quick Charts. You only need one chart module. Restart Plasma after installing a module so the widget can detect it.

Radar map and hybrid-GPU compatibility notes

The embedded radar uses Qt WebEngine. On some hybrid-GPU laptops running Wayland, a driver-level conflict can cause Plasma to crash when the embedded browser view first renders. An experimental workaround is available in the widget's General settings. It disables GPU-accelerated compositing inside the browser view and requires logging out and back in to take effect.

If MangoHud or another LD_PRELOAD overlay is active in plasmashell, the widget may avoid loading the embedded radar. In that case, use Open radar in browser, or try Load embedded radar anyway at your own risk. See the README for the full explanation.
