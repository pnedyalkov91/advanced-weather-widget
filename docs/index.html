02 / Capabilities

Features

Everything you need to follow local weather — from everyday conditions to the wider environment around you.

Location with precision

Automatic location detection through GeoClue2 or manual search with OpenStreetMap and Photon geocoding. Use the integrated map picker to pin an exact location, with timezone, altitude and localized city names.

GEOCLUE2OPENSTREETMAPPHOTON

Adaptive weather providers

Adaptive mode can move to another configured provider when a source is unavailable. Open-Meteo can also prefer national high-resolution models for more precise regional forecasts.

ADAPTIVE FAILOVERREGIONAL MODELS

Environmental and space data

Follow UV, air quality (CAQI), pollen, geomagnetic Kp and G indices, and aurora probability. Choose the metrics that matter to you.

UV INDEXCAQIPOLLENKP / G INDEX

Sun and Moon tracking

Optional Sun Arc and Moon Path visualizations show sunrise, sunset, lunar phases, moonrise and moonset.

SUNRISE / SUNSETMOON PHASES

Detailed forecast graphs

Daily Standard or Graphs layouts, plus hourly Cards, Strip or Graphs. Enable additional data series, reorder them and expand a day to inspect its hours.

UP TO 16 DAYSHOURLYCUSTOM GRAPHS

History and summaries

Browse previous days, weeks and months with interactive charts and summary tiles for temperature, precipitation, wind, sunshine, humidity, pressure and cloud cover.

OPEN-METEO HISTORICAL APIQT GRAPHS

Weather alerts and notifications

Receive KDE notifications for forecasts, UV and space weather, along with alerts from MeteoAlarm, NOAA NWS, LibreWXR, KDE’s FOSS Public Alert Server and supported provider sources. Notification types and sounds are configurable.

METEOALARMNOAA NWSKDE ALERTS

Adaptable desktop layouts

Use Single line, Simple or multiline panel styles. Choose Advanced mode with tabs or a tab-free Simple widget, and customize icon styles and forecast details.

04 / Getting started

Installation

The KDE Store is the recommended way to install Advanced Weather Widget. Optional features may require additional Qt or KDE modules.

Install directly from KDE Store

Install the widget from Plasma without cloning the repository or running commands.

  1. Right-click your desktop or Plasma panel.
  2. Select Add Widgets….
  3. Choose Get New Widgets → Download New Plasma Widgets.
  4. Search for Advanced Weather Widget and click Install.
Open KDE Store ↗

Install from source

For development or testing, clone the repository and install the Plasma applet package.

git clone https://github.com/pnedyalkov91/advanced-weather-widget.git
cd advanced-weather-widget
kpackagetool6 --type Plasma/Applet --install .
rm -rf ~/.cache/plasmashell/qmlcache
systemctl --user restart plasma-plasmashell

See the README for development notes and radar-map rebuild instructions.

Radar and hybrid-GPU troubleshooting

On some hybrid-GPU laptops running Wayland, Qt WebEngine may conflict with graphics drivers when the embedded radar first renders. The widget provides an experimental workaround in General settings. It disables GPU-accelerated compositing inside the browser view and requires logging out and back in to take effect. It affects other Chromium-based embedded views in the session, too.

When MangoHud or another LD_PRELOAD overlay is active in plasmashell, the widget may offer to open the radar in a browser instead. See the README for the full notes.

The widget uses Qt Graphs when available and falls back to KDE Quick Charts. Only one chart module is needed. Restart Plasma after installing a module so it can be detected.

06 / About the project

A weather widget for the KDE desktop.

Advanced Weather Widget

Created and maintained by Petar Nedyalkov, Advanced Weather Widget is designed specifically for KDE Plasma 6. It combines a flexible panel display with a detailed desktop view, configurable weather data, multiple providers, maps, alerts and historical information. The project is licensed under GNU GPL-3.0-or-later.

Project maintainer on GitHub ↗

Privacy and data handling

The widget does not collect telemetry or track users. Location coordinates are used to request local weather data from the selected provider and to support location, geocoding and map features. Review the privacy terms of the data providers you choose.

Third-party data, libraries and acknowledgements
  • Open-Meteo provides forecast and historical weather data; historical data is offered under CC BY 4.0.
  • RainViewer and LibreWXR are used for radar data and related services.
  • OpenStreetMap contributors provide map data under the ODbL; Photon is used for geocoding.
  • Leaflet is used for interactive map rendering (BSD 2-Clause License).
  • Weather icon resources include Weather Icons (SIL OFL 1.1) and Meteocons by Bas Milius (MIT License).
  • Sun and Moon calculations use SunCalc (BSD License).
  • Charts use Qt Graphs, with KDE Quick Charts as a fallback.
  • Weather alerts can use KDE’s FOSS Public Alert Server; space-weather information uses data from NOAA SWPC.

See the project README and bundled license files for complete third-party notices and attribution details.
